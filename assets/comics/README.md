# SUCCU WORLD 4コマ 入稿フォルダ

ピックした4コマ（日本語 / 英語）をここに入れてください。
ここは**マスター置き場**（git非公開）。公開用の軽量WebPは私が生成して `assets/webp/comics/` に出力し、SUCCU WORLDページに組み込みます。

## 入れ方
- 日本語版 → `assets/comics/jp/`
- 英語版 → `assets/comics/en/`

## ファイル名の規約（そろえてくれると自動で紐付け・並べ替えできます）
```
<番号3桁>_<YYYYMMDD>_<登場キャラをハイフン区切り>.png
```
例:
- `assets/comics/jp/001_20260910_RINA-MAYU.png`
- `assets/comics/en/001_20260910_RINA-MAYU.png`   ← 日本語と同じ番号にすると JP/EN がペアになります

- 番号 = 表示順（新しい順に並べます。逆順希望なら教えてください）
- 日付 = カード表示の日付に使用
- キャラ = カードのタグ／キャラ絞り込みに使用（RAY MAYU AYA HIKA KOTO RINA NOX）
- タイトルを付けたい場合は、別途「番号: タイトル」の一覧をテキストでください（なければ日付のみ表示）

拡張子は png / jpg どちらでもOK。まず数点だけでも構いません（動作確認して量産対応します）。
